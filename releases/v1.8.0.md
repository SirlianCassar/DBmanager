# DBmanager v1.8.0

Nouvel onglet Spare parts US : la liste des pièces que Cairm surligne en rouge sur Portal se gère dans la base, avec le message affiché.

- Liste SKU + nom de pièce : ajout, modification directe dans le tableau, retrait et filtre. Un SKU en double ou mal formé est refusé.
- Un seul bouton « Modifier le message » pour le texte commun à toutes les pièces, avec retour au message par défaut.
- Une base sans liste peut reprendre en un clic la liste intégrée à Cairm (133 pièces).
- La liste est enregistrée dans la clé `usExpressSpareParts` ; Cairm 0.60.0 la lit à l'actualisation de la base et la garde jusqu'à la base suivante.
